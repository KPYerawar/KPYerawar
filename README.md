### 💻 Key Projects

* **RISC-V Processor Design & Physical Implementation**
    * Designed and verified a 32-bit RISC-V (RV32I ISA) core using Verilog.
    * Successfully executed the complete RTL-to-GDSII physical design flow targeting legalized placement for a ~93K gate design.
    * Validated the core on a Xilinx Artix-7 FPGA board with real-time hardware-in-the-loop verification.

* **Systolic Array AI Accelerator (Transformer Edge Inference)**
    * Developing a hardware accelerator optimized for matrix multiplication in Transformer-based edge models.
    * Focused on localized data reuse and processing element (PE) efficiency to optimize throughput and power.

* **FPGA-Based Communication & Peripherals**
    * Developed a custom Verilog I2C Master Core to interface an MPU6050 inertial sensor with an Artix-7 FPGA, processing real-time acceleration data.
